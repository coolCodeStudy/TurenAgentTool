## Maintenance Rules

- Product docs define user problems, flows, scope, non-goals, and acceptance criteria.
- Tech plans define implementation details.
- Keep product docs in English when editing, except for command examples or user-facing product phrases.
- If a product doc becomes stale, mark it superseded and link the replacement.
