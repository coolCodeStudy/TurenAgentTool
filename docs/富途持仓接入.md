# 富途持仓接入

目标：用户在钉钉询问 `我的持仓` 时，云端系统实时读取富途持仓并回复。第一版只读，不下单，不解锁交易。

## 推荐架构

```text
钉钉群
  -> dingtalk-stream-bot
  -> command_router
  -> FutuPositionProvider
  -> ECS 本机 OpenD:11111
  -> 富途服务器
```

OpenD 跑在 ECS 宿主机上，InvestmentKnowledge 容器通过 `host.docker.internal:11111` 访问。Compose 已配置 `host-gateway` 映射。安全组不要开放 `11111`。

## 当前能力

- 新增查询指令：
  - `我的持仓`
  - `我的仓位`
  - `当前持仓`
  - `当前仓位`
  - `持仓`
  - `仓位`
- 使用 `futu-api` 调用 `position_list_query()`。
- 默认 20 秒短缓存，避免钉钉反复询问时触发富途查询频率限制。
- 当前不写入 `positions` 表，只返回实时查询结果。

## 配置项

```text
FUTU_OPEND_HOST=host.docker.internal
FUTU_OPEND_PORT=11111
FUTU_SECURITY_FIRM=FUTUSECURITIES
FUTU_TRADE_MARKET=HK
FUTU_TRADE_ENV=REAL
FUTU_ACCOUNT_ID=0
FUTU_ACCOUNT_INDEX=0
FUTU_POSITION_CACHE_SECONDS=20
FUTU_POSITION_REFRESH_CACHE=true
```

建议优先配置 `FUTU_ACCOUNT_ID`。如果账号只有一个，也可以先用 `FUTU_ACCOUNT_INDEX=0`。

## ECS 准备

1. 在 ECS 上安装并启动富途 OpenD。
2. 登录富途账号，完成设备验证。
3. 确认 OpenD 只监听本机或至少安全组不开放 `11111`。
4. 如果 OpenD 只监听 `127.0.0.1` 且容器连不上，需要让 OpenD 监听宿主机可被 Docker bridge 访问的地址，或后续改为 OpenD 容器化部署。
5. 重启 `dingtalk-stream-bot` 后，在钉钉问：

```text
@机器人 我的持仓
```

## 安全边界

- 第一版只读持仓。
- 不调用 `unlock_trade()`。
- 不保存交易密码。
- 不实现下单、改单、撤单。
- 钉钉写入知识库仍受 `DINGTALK_STREAM_ALLOW_WRITE` 和 sender 白名单控制。
