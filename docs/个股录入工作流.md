# 个股录入工作流

## 目标

个股录入流程的目标是让大模型成为研究员，但不让大模型直接决定入库。所有模型输出都必须经过校验和用户确认。

## 标准流程

```text
1. 收集资料来源
2. 生成 research_draft skeleton
3. 生成补全 prompt
4. 使用模型补全 enriched draft
5. 校验 enriched draft
6. 生成人工审阅稿
7. 用户确认或修改
8. confirmed 入库
```

## 推荐命令

### 1. 准备研究工作流

手工资料来源：

```bash
python scripts/research_stock.py 000660 KR \
  --manual-source-file examples/manual_sources/sk_hynix_sources.json
```

公开网页来源：

```bash
python scripts/research_stock.py 000660 KR --name SK海力士 \
  --source-url fact_sheet=https://news.skhynix.com/corporate/fact-sheet/
```

输出：

```text
drafts/000660_KR_research_draft.json
drafts/000660_KR_research_draft.prompt.md
```

### 2. 模型补全

使用 mock provider 测试流程：

```bash
python scripts/enrich_research_draft.py drafts/000660_KR_research_draft.json --provider mock
```

使用 OpenAI provider：

```bash
python scripts/enrich_research_draft.py drafts/000660_KR_research_draft.json --provider openai
```

输出：

```text
drafts/000660_KR_research_draft.enriched.json
```

### 3. 校验

```bash
python scripts/validate_research_draft.py drafts/000660_KR_research_draft.enriched.json
```

### 4. 生成人工审阅稿

```bash
python scripts/review_research_draft.py drafts/000660_KR_research_draft.enriched.json
```

输出：

```text
drafts/000660_KR_research_draft.enriched.review.md
```

### 5. 用户确认后入库

```bash
python scripts/import_research_draft.py drafts/000660_KR_research_draft.enriched.json --confirmed
```

## OpenAI 配置

真实调用 OpenAI provider 前，在本地 `.env` 中配置：

```text
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.2
```

不要把 `.env` 提交到 git。

## 设计原则

- provider 只负责收集资料。
- 模型负责补全候选草稿。
- validator 负责检查结构和来源引用。
- review 文件负责给用户确认。
- confirmed import 才能把模型输出标记为用户确认。
- 用户心得只能写用户明确表达过的观点。
